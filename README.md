# CPU Scheduling Algorithm Simulator

## Overview
This project is a **CPU Scheduling Algorithm Simulator** built in C++.  
It demonstrates how different scheduling techniques manage process execution in an operating system.  
The program calculates essential performance metrics such as **Completion Time, Turnaround Time, Waiting Time**, and their averages, helping in analyzing efficiency of algorithms.  

---

##  Key Features
- Implements **multiple scheduling algorithms**:
- First Come First Served (FCFS)
- Shortest Job First (SJF - Preemptive)
- Priority Scheduling (Preemptive)
- Highest Response Ratio Next (HRRN)
- Calculates process metrics: Completion, Waiting, Turnaround times
- Provides **average turnaround time and waiting time**
- Interactive **menu-driven interface** for user input
- Demonstrates **process scheduling step by step** for learning

---

## Applications
- **Educational tool** for students learning operating system concepts
- Useful for **visualizing and comparing scheduling techniques**
- Helps analyze efficiency of different algorithms in terms of turnaround and waiting times
- Serves as a **base project** to extend into Gantt chart visualizations or GUI-based simulators
